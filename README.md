# Nubivanta Fit — piloto
Aplicación personal de nutrición y entrenamientos, preparada para publicarse con GitHub Pages.

## Publicación
1. Subir `index.html`, `icon.svg`, `manifest.webmanifest` y `.nojekyll` a la raíz del repositorio.
2. En **Settings > Pages**, elegir **Deploy from a branch**, `main` y carpeta `/(root)`.
3. Abrir `https://joseantonioaraujojimenez-cpu.github.io/NUBIVANTA-FIT/` cuando Pages indique que está publicado.

**Privacidad:** no introducir datos personales ni fotografías en el repositorio. Los datos introducidos en el piloto se guardan en el navegador del dispositivo; no hay sincronización entre dispositivos. El código del repositorio es público.
