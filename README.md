# Nubivanta Fit — GitHub Pages

Primera versión piloto. No conectar todavía servicios de IA ni colocar claves privadas en estos archivos.

## Publicación
1. Crea un repositorio público en GitHub llamado `nubivanta-fit` (sin archivos iniciales).
2. Sube los archivos del contenido de esta carpeta a la raíz del repositorio, **no el ZIP**.
3. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, directorio `/(root)` y guarda.
4. Abre la URL indicada en Pages, normalmente `https://TU-USUARIO.github.io/nubivanta-fit/`.
5. En Safari de iPhone, **Compartir → Añadir a pantalla de inicio**.

**Privacidad:** el código publicado es público. Los datos se almacenan localmente en el navegador del dispositivo; no se sincronizan ni se respaldan automáticamente. Evita utilizar datos sensibles reales en esta fase piloto.
